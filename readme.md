## 盘后规则

1. 最近120个完整交易日的前期高点之后回撤**至少20%**，高点及后续低点均须早于最近三日上涨开始；最近三个完整交易日收盘逐日上升。
2. 最近三日每天涨幅在 `(0%,3%]`，需要四日价格作为基准。仅当相邻原价/复权OHLC一致、公司行动可解释、价格误差区间不跨阈值时计算；除权口径不明确不猜测涨幅。
3. 三天全天量分别比前一日增加 `(0%,50%]`，需要四个连续完整交易日，禁止分钟累计量、比例推算或旧日替代。
4. 最新正式财报归母净利润>0，或未被财报覆盖的有效正式预告扭亏；仍核验公告版本、报告期、盈利下限及上年同期亏损。
5. 第三天全天主力净流入>0，使用东方财富资金日线的大单+超大单统计，日期必须与选股日完全一致。

## 定时更新

Pages工作流在周一至周五北京时间20:30触发，交易所日历判断休市；休市不扫描。GitHub Actions的定时触发可能延迟，60天仓库不活跃时GitHub也可能停用公共仓库定时任务，需在Actions恢复。

先检查上证指数120日历和资金样本是否已更新至当日。未就绪每60秒核验一次，最多6次，仍失败则发布“无法判断/等待数据”诊断，不以最近可用日替代当日。预检仅确认数据源样本，不声称每只股票完整；个股逐项核验日期及字段。

就绪后只扫描一次，完成快照提交到`main`作为当天完成标记；同一天已完成全量扫描不再重复。定时提交使用仓库自带`GITHUB_TOKEN`，不新增收费凭证。若提交权限/分支策略阻止持久化，工作流会明确失败，不能声称自动更新成功。Pages同一工作流发布根路径及`/static/`。

网页刷新仅读取已发布JSON，不触发新扫描。当前扫描日与网页应核验交易日不同，则旧记录只作历史记录，不能作为当天入选。盘后结果按日期保存，不再按盘中180秒规则隐藏；休市期间仍可查看上一完整选股日。

Python 3.10+标准库，无需密钥或安装依赖。

```bash

python3 scripts/scan_after_close.py --workers 8 --readiness-attempts 6

# 明确指定已收盘交易日做核验，不冒充当前交易日
python3 scripts/scan_after_close.py --date 2026-09-30 --symbols 600519,000001,600036

python3 app.py --host 0.0.0.0 --port 8000
python3 -m unittest discover -s tests -q
node tests/test_frontend.cjs
```
