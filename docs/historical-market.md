## 逐股分阶段筛选

1. 请求少量不复权日线，确认最新三个交易日与上证指数交易日历一致，并验证两组全天量增幅均在 `(0%,50%]`。不满足必要条件即可排除，其他条件显示未继续请求；停牌、日期不足等记为无法判断。
2. 对剩余股票分别请求160条不复权及前复权日线，核对所请求市场的证券身份。要求120个同日期完整交易日，不足不补数据。涨幅采用同源相邻原始收盘价，仅在两日复权/原始OHLC一致、没有无法解释的公司行动且价格误差区间完全位于 `(0%,3%]` 时通过。详见 [复权与精度核验](historical-calculation.md)。120日回撤仍使用原有前复权口径，高点之后跌幅严格超过20%，不放宽阈值。
3. 对技术历史条件通过者逐股请求最新正式财报（`RPT_LICO_FN_CPD`），归母净利润严格为正即可满足财务条件；否则检查正式预告（`RPT_PUBLIC_OP_NEWPREDICT`）。要求有效的最新“扭亏”公告、净利润预计下限为正及上年同期亏损，且未被更新财报覆盖。财报或必要预告缺失为无法判断，不默认为盈利或没有预告。

“历史候选”只包含上述历史技术条件与财务条件均通过的股票。技术通过但财务不满足/无法判断另列。全部候选 `formalSelection=false`、`status=unknown`；第三天有效报价、今日转向、与前日同一分钟累计量及当天主力净流入均未被这些历史数据证实，因此不会写入正式入选结果。

行情停在2026-09-30符合已核实的国庆休市安排。当前三个已完成交易日为9月28/29/30，检查的是9月29/30涨幅及全天量，120日窗口自4月9日起。休市提示“休市，等待下一交易日”；历史报告不是当前盘中结果。财报公告日期、报告期、采集时间独立展示。

## 统计与失败定义

本次最终扫描于北京时间2026-10-06 07:29完成：5572/5572只实际处理，5286只放量条件不满足；253只完成120日配对分析，其中124只历史条件不满足、69只历史精度/复权无法判断、60只技术通过。60只全部完成财务核验，45只财务通过形成历史候选，15只财务不满足，没有财务未知者。另33只缺少必要日期或字段，合计102只无法判断。实际请求6206次（含证券列表、日历、财务及有限重试）。

102只未知的具体分布：65只涨幅误差区间跨越阈值，21只最近交易日期不完整，8只缺少完整120日，4只缺少明确复权字段，3只相邻复权/原价不同，1只有无法解释的公司行动元数据。本次最终未遗留HTTP请求失败；字段及口径不足仍保留未知，不能视为通过。行情截至9月30日，正式入选0只。

- `universeCount`：完整分页核验的供应商证券池数量。
- `scannedCount` / `exchangeScannedCounts`：实际逐股请求并处理完毕的数量，包含已明确排除及无法判断；不把仅获取列表当成扫描。
- `fullHistoryAnalyzedCount`：完成120日配对历史分析者；前置放量不满足者没有请求完整历史，不计入此项。
- `financialCheckedCount`：技术历史通过且执行了财务核验者。
- `failureCount`：逐股采集失败、120日不足/停牌、复权/精度不明确，或财务无法判断，按股票计数；明确不满足条件不计作接口失败。
- `coverageComplete`：完整列表中的每只股票都被实际处理，不代表缺失记录已经得到确定判断。失败明细仍保留。

`static/historical-market.json` 供网页展示数量、数据日期、阶段统计、候选证据和失败原因；`static/historical-market-audit.json` 保留全部股票的阶段结果。网络截断、超时、网关502/503转换为明确失败，有限重试后不会使用旧数据。腾讯列表的资金字段未核验数据时间，不能替代当日主力资金。

## 更新方式

本地执行 `python3 scripts/scan_history_market.py --workers 8`，完成后提交发布；或 GitHub Actions 手动运行 Pages 工作流，勾选 `refresh_history`。少量验证可传 `--symbols 600519,000001,920982`，会明确标记非全市场，退出码2。退出码0仅表示全证券池已处理；数据无法判断仍单列。

网页刷新只重新读取已发布JSON，不发起全市场采集。没有购买数据、启用付费接口或把密钥写进仓库。盘中链路尚未完整验证；下一交易日需另行获取新鲜、准确对齐的报价、两日分钟量和主力资金，全部五项通过才可正式入选。
